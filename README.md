# Keista Mall

Global sourcing & import agency site.

- `index.html` — public landing page with sourcing plan, trust proof, sign-up/login, and quote handoff
- `quote.html` — dedicated sourcing quote form
- `dashboard.html` — private client workspace for quote requests, orders, and shipment milestones
- `admin.html` — staff dashboard for reviewing and updating quote requests (requires admin account)
- `competitor-benchmark.md` — benchmark and rationale for the customer-journey redesign

## Stack
- Static HTML/CSS/JS, no build step
- Backend: Supabase (auth + database)
- Hosting: Netlify (auto-deploys from this repo)
